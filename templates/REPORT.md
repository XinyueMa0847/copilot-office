# Task or study report

Project/study ID: `{{PROJECT_ID}}`

## Scope and identity

Project/study ID, task/request ID, employee/profile, date, question, acceptance
criteria, and exclusions.

## Outcome

What was accomplished and what remains incomplete. Distinguish changes made,
checks performed, run completion, and validated improvement.

## Evidence

Link relevant files, revisions/local changes, commands/configuration, run IDs,
artifacts, and verification output. Include timestamps for runtime observations.
Do not report tests or source access that did not actually occur.

For external research, include search approach, coverage/retrieval dates, verified
titles/authors/year and URL/DOI, and a source-to-claim comparison. Distinguish
full-text access from abstracts or excerpts.

## Interpretation and limitations

Separate observations, source claims, interpretation, causal claims, uncertainty,
confounders, missing data, and contradictory evidence.

## Next action

Smallest justified next step, remaining decision, dependencies, and resource
implications. A recommendation is not permission to start new work.
